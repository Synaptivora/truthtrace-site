# TruthTrace 产品官网

AI 现实档案调查局 —— 上传材料、还原事件、追踪承诺，让每条结论都点回原始证据。

本仓库是 TruthTrace 的对外产品官网（静态站点），与产品源码仓库 [Synaptivora/truthtrace](https://github.com/Synaptivora/truthtrace) 相互独立。

## 结构

- `index.html` — 首页
- `features.html` — 产品功能
- `architecture.html` — 技术架构
- `guide.html` — 快速开始
- `about.html` — 关于我们
- `css/style.css` — 统一样式
- `js/main.js` — 通用交互

## 部署

推送至 `main` 分支即自动部署到 GitHub Pages：https://synaptivora.github.io/truthtrace-site/
