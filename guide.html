快速开始

三步跑起来

无需密钥即可跑通完整演示（虚构校园退款纠纷），感受从材料到可核查结论的完整流程。

1

安装依赖

npm install
2

启动开发服务器

npm run dev

默认 AI_PROVIDER=mock，无需密钥即可跑通完整演示。

3

打开浏览器

http://localhost:3000
启用真实模型

接入多模态模型

复制 .env.example 为 .env.local，填入你的密钥。

AI_PROVIDER=openai
AI_API_KEY=你的密钥
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4.1-mini
自动判断：AI_PROVIDER=auto 时，填了 AI_API_KEY 就走真实模型，没填则回退到本地规则分析（按发言人/时间做确定性统计）。
自主调查

本地自主调查

使用 Node.js 24，在仓库根目录执行以下命令，同时启动 Next.js 与独立调查 Worker（仅监听 127.0.0.1）。

npm ci
npm run dev:local

生产模式

先 npm run build，再 npm run start:local。也可分别运行 npm run dev 与 npm run worker。

断点续跑

关闭浏览器不会终止 Worker；重启后回收过期租约并从已完成 Skill 继续。

对话 Agent

配置「咪探长」

点击右下角「和咪探长聊聊」→ 打开齿轮 → 选择供应商 → 填写 API 地址、模型 ID 与 Key → 测试连接 → 发送问题。

AGENT_PROVIDER=deepseek
AGENT_PROTOCOL=openai
AGENT_BASE_URL=https://api.deepseek.com
AGENT_MODEL=填写当前可用模型ID
AGENT_API_KEY=填写自己的密钥
AGENT_TOOLS=true
支持 18+ 家供应商预设与自定义入口；协议支持 openai（Chat Completions）、anthropic（Messages）、responses。
